一个单文件静态站点，把《太乙金华宗旨》十三章原文、逐段讲解、四阶实操，以及一个能用的日课计时与打卡工具放在一起。零依赖，双击 `index.html` 就能读、能坐、能记。整理者：**澄一**（印见左，`assets/seal-chengyi.svg`）。

- 旧题吕洞宾，十三章，清刻本系统
- 原文全录，逐段白话讲解，章末列要点、一句实操、已知异文
- 原文页可切「横排 / 竖排」：竖排只把原文按古书自右向左排，白话讲解仍横排（竖排的今译一行三四个字，读不下去）；只改版式，不改字、不改段
- 可直接打印或存 PDF：只印当前视图，去掉顶栏与操作件，末尾保留「澄一」印与许可声明
- 实操按第三章「回者止也，光者观也」拆成四阶：垂帘 → 系心缘中 → 听息 → 止观

- 日课：调身 / 回光 / 收功三阶段计时，收功后记一笔，统计连续天数与近三十天
- 首次访问有一步到位的引导（读一段 / 练一次 / 记一笔），关掉后从首页「新手引导」可再打开
- 记录只存本机 `localStorage`（键 `tyjh.log.v1`、`tyjh.onboard.v1`、`tyjh.view.v1`），日课可导出 JSON；桌面与手机都可用

## 为什么做这个

这本书在坊间被讲成了两件它明确否掉的事：一是「守眉心」，二是「搬运周天」。原文里：

- 第三章：「不必言头中」「不必着意于中宫」「缘者缘此为端倪，非有定着也」——系念不是守窍。
- 第十二章：「周天非以气作主，以心到为妙诀」「并无采法，言采者大谬矣」。
- 第十三章：「夹脊者，非背上轮子，乃直透玉京大路也」。

所以站内的讲解不追求玄谈，只做一件事：把原书可执行的部分摘出来，把原书自己否掉的岔路标出来。凡属推断，写明「不确定」。

## 维护笔记

- 本地提交与远端提交的 SHA **可以不同而内容相同**。正常 `git push` 到 github.com:443 在本机不通（连接被重置），改动改由 GitHub API 提交：以远端 head 为父提交，按本地内容建 tree 再提交。因此远端 SHA 与本地不是同一个对象。比对两边的依据不是 SHA，而是文件字节——`tools/check_live.py` 就是干这个的，一致时它报 `identical`。
- 走 API 的推送脚本是 `tools/push_via_api.py`（`GITHUB_TOKEN=... python tools/push_via_api.py`）。**它必须带 `core.quotepath=false` 读 `git ls-tree`**：否则 git 会把 `校记.md` 这类非 ASCII 路径输出成 `"\346\240\241\350\256\226.md"` 八进制串，这个串会被当成真文件名写到远端，中文文件名就永远 404。脚本里已加反斜杠断言，遇到这种路径直接报错停下。
- Pages 构建约 30–45 秒。提交后拉 `GET /repos/{owner}/{repo}/pages/builds/latest`，看到 `status: built` 再核内容，否则可能读到上一版。
- 改 `校记.md` 的异文表后必须重跑 `python tools/errata.py`，不要手改 `data/errata.json`；结构测试会拿校记表行数与 JSON 条数比对。
