# 太乙金华宗旨 · 回光实操

<img src="assets/logo.svg" width="88" height="88" alt="回光"> <img src="assets/seal-chengyi.svg" width="88" height="88" alt="澄一印">

一个单文件静态站点，把《太乙金华宗旨》十三章原文、逐段讲解、四阶实操，以及一个能用的日课计时与打卡工具放在一起。零依赖，双击 `index.html` 就能读、能坐、能记。整理者：**澄一**（印见左，`assets/seal-chengyi.svg`）。

- 旧题吕洞宾，十三章，清刻本系统
- 原文全录，逐段白话讲解，章末列要点、一句实操、已知异文
- 原文页可切「横排 / 竖排」：竖排照古书自右向左，只改版式，不改字、不改段
- 可直接打印或存 PDF：只印当前视图，去掉顶栏与操作件，末尾保留「澄一」印与许可声明
- 实操按第三章「回者止也，光者观也」拆成四阶：垂帘 → 系心缘中 → 听息 → 止观
- 垂帘一阶配一张可拖动的侧视剖面：上睑下垂到什么程度、视线落在何处，三档可辨（示意图，非解剖比例）
- 日课：调身 / 回光 / 收功三阶段计时，收功后记一笔，统计连续天数与近三十天
- 首次访问有一步到位的引导（读一段 / 练一次 / 记一笔），关掉后从首页「新手引导」可再打开
- 记录只存本机 `localStorage`（键 `tyjh.log.v1`、`tyjh.onboard.v1`、`tyjh.view.v1`），日课可导出 JSON；桌面与手机都可用

## 为什么做这个

这本书在坊间被讲成了两件它明确否掉的事：一是「守眉心」，二是「搬运周天」。原文里：

- 第三章：「不必言头中」「不必着意于中宫」「缘者缘此为端倪，非有定着也」——系念不是守窍。
- 第十二章：「周天非以气作主，以心到为妙诀」「并无采法，言采者大谬矣」。
- 第十三章：「夹脊者，非背上轮子，乃直透玉京大路也」。

所以站内的讲解不追求玄谈，只做一件事：把原书可执行的部分摘出来，把原书自己否掉的岔路标出来。凡属推断，写明「不确定」。

